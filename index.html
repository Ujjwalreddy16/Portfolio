Published Work

EyeCommand: Intelligent Gaze & Blink Interface

IEEE Conference · K U. Reddy, K. M, P. V. K. Reddy, V. M. Pathapati, S. Patil

An assistive computing system for cursor control and click operations using only the eyes and a standard webcam. Delivers a low-cost alternative to infrared eye-tracking hardware (typically $1000+) while keeping practical accuracy and reliability, with a fully open-source implementation for reproducibility and real-world deployment for users with motor impairments.

Genetic Algorithm-Based Path Planning Using Adaptive Operators

International Journal of Innovative Research in Technology (IJIRT), 2025 · K U. Reddy, A. M. Gorte

A GA-based path planning system for robots navigating dynamic grid/maze environments. Adaptive crossover and mutation operators improve convergence speed and solution accuracy over traditional GA; simulation experiments demonstrate gains in search efficiency and adaptability.
